# Tanzania Computing Students

A national open-source repository for computing students in Tanzania.

## Purpose

This repository connects computing students through:

- Learning
- Projects
- Research
- Programming
- Networking
- Cybersecurity
- Software engineering
- Web development
- Cloud computing
- Artificial intelligence
- Data science
- Final-year projects
- Experiences
- Opportunities
