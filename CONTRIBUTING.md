# Contributing to TCOSC

Thank you for contributing to the Tanzania Computing Open Source Community.

TCOSC is built around open collaboration, practical learning, technical
quality, and long-term maintenance.

## Ways to Contribute

You can contribute through:

- Code
- Documentation
- Research
- Tutorials
- Learning materials
- Software projects
- Cybersecurity labs
- CTF challenges
- Writeups
- Testing
- Bug reports
- Feature proposals
- Reviews
- Examples
- Mentorship

## Basic Workflow

1. Find an existing issue or create a new one.
2. Discuss the proposed contribution when necessary.
3. Fork the repository if required.
4. Create a dedicated branch.
5. Make your changes.
6. Test your work.
7. Update documentation.
8. Commit your changes.
9. Open a Pull Request.
10. Respond to review feedback.
11. Maintainers review and merge accepted contributions.

## Branch Naming

Recommended:

feature/short-description
fix/short-description
docs/short-description
research/short-description
lab/short-description
project/short-description

## Commit Messages

Use clear commit messages.

Examples:

Add networking fundamentals roadmap

Fix broken learning resource link

Add web security laboratory

Improve project documentation

Add authentication research notes

## Pull Requests

Every Pull Request should explain:

- What was changed
- Why it was changed
- How it was tested
- Any relevant issue
- Any limitations or known problems

## Quality

Contributors should make reasonable efforts to ensure that contributions
are:

- Accurate
- Understandable
- Reproducible
- Properly licensed
- Safe
- Maintainable
- Properly documented

## Originality and Licensing

Do not submit material that you do not have permission to redistribute.

Third-party content must retain its original licensing requirements.

## Respect

Contributors must follow the TCOSC Code of Conduct.
