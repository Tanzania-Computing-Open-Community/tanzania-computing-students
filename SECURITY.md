# Security Policy

TCOSC takes the security of its repositories and community infrastructure
seriously.

## Reporting Security Issues

Do not publicly disclose sensitive security vulnerabilities before they
have been responsibly reviewed.

Use GitHub's private vulnerability reporting/security reporting mechanism
where available.

If private reporting is unavailable for a specific repository, contact the
repository maintainers privately before public disclosure.

## Do Not Include

Security reports must not include unnecessary:

- Passwords
- Authentication tokens
- Private keys
- Personal data
- Confidential information

## Responsible Disclosure

Security researchers are encouraged to provide:

- A clear description
- Affected component
- Reproduction steps
- Security impact
- Evidence where appropriate
- Suggested remediation where possible

## Scope

This policy applies to TCOSC-controlled repositories and infrastructure.
