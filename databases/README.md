# Database Learning Resources

## Overview

This directory contains curated learning materials for Databases, including study notes, textbooks, lecture slides, research papers, practical exercises, laboratory guides, assignments, sample databases, and project resources.

The collection supports computing students, self-learners, educators, researchers, and open-source contributors across Tanzania in developing theoretical knowledge and practical database management skills.

## Practical Learning and Data Safety

Exercises should provide clear setup instructions, sample data, and reproducible steps where applicable.

Use synthetic, public, or properly authorized datasets for practice. Never publish database passwords, access tokens, private keys, confidential records, or personally identifiable information without appropriate authorization and safeguards.

Database security exercises should be conducted only in environments you own or are explicitly authorized to test.

## Copyright and Licensing

Only upload materials whose licenses or copyright permissions allow redistribution. Free access or downloading does not automatically grant permission to republish a resource.

Preserve required attribution, copyright notices, license files, and other license conditions. When redistribution is prohibited or unclear, provide a link to the original source instead of uploading a copy.

Check the licenses and terms of use for sample databases, datasets, software, and third-party resources before sharing them.

## Contribution Guidelines

Contributors should prioritize accurate, useful, accessible, and appropriately licensed learning materials.

- Organize resources into relevant directories.
- Use descriptive filenames.
- Include original source links and licensing information.
- Avoid unnecessary duplication.
- Provide runnable SQL examples where possible.
- Document database versions and prerequisites.
- Include sample schemas and setup instructions when appropriate.
- Explain query results and important design decisions.
- Keep examples free of credentials and sensitive data.
- Keep materials technically accurate and up to date.

Contributions should encourage practical database design, efficient querying, secure administration, data integrity, research, and open collaboration.
