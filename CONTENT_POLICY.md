# TCOSC Content Policy

TCOSC is an open-source computing community.

Content should contribute to learning, research, software development,
technical collaboration, or responsible technology practice.

## Acceptable Content

Examples include:

- Programming
- Software engineering
- Networking
- Operating systems
- Databases
- Web development
- Mobile development
- Cloud computing
- Artificial intelligence
- Data science
- Cybersecurity
- Digital forensics
- Malware analysis
- Secure development
- Research
- Open-source software
- Technical documentation
- Learning resources
- Projects
- Tutorials
- CTF challenges
- Security writeups
- Vulnerability research

## Cybersecurity Content

Cybersecurity material must be presented for legitimate educational,
research, defensive, or authorized testing purposes.

Do not publish:

- Stolen credentials
- Personal confidential information
- Private keys
- Authentication tokens
- Malicious secrets
- Unauthorized access information
- Instructions intended to facilitate attacks against real systems
  without authorization

## Third-Party Material

Contributors must respect:

- Copyright
- Licenses
- Attribution requirements
- Terms of redistribution

Do not upload material simply because it is publicly accessible.

## Quality

Content should be:

- Technically relevant
- Understandable
- Useful
- Properly attributed
- Appropriately licensed
- Maintained when necessary
