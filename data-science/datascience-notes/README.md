# Data Science Learning Resources

## Overview

This directory contains curated learning materials for Data Science, including study notes, textbooks, lecture slides, research papers, practical exercises, laboratory guides, assignments, datasets, and project resources.

The collection supports computing students, self-learners, educators, researchers, and open-source contributors across Tanzania in developing theoretical knowledge and practical data science skills.

## Resource Categories

- Learning notes and study guides
- Books and textbooks
- Lecture slides and presentations
- Research papers and technical reports
- Practical exercises and laboratory guides
- Assignments and assessments
- Datasets for learning and experimentation
- Data analysis and visualization projects
- Statistical analysis resources
- Data science tools, libraries, and frameworks
- External courses and educational resources

## Learning Topics

Resources may cover:

- Data science fundamentals and workflows

- Data collection and acquisition
- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Data visualization and storytelling
- Python and R for data science

- Data manipulation and transformation
- Statistical modeling and inference

- Model evaluation and validation
- Time series analysis and forecasting
- Big data processing and analytics
- Data engineering fundamentals

## Resource Information

Where available, each resource should include:

- Title and author
- Publishing institution or organization
- Publication date or version
- Original source URL
- File format
- Intended learning level
- Topics covered
- Dataset source and documentation
- License and redistribution permissions
- Required software, libraries, or environment

## Data and Reproducibility

Datasets should include their original source, documentation, relevant licensing information, and descriptions of their fields where available.

Practical exercises and projects should provide clear instructions, necessary dependencies, and reproducible steps. Do not include private, confidential, or personally identifiable data without appropriate authorization and safeguards.

## Copyright and Licensing

Only upload materials and datasets whose licenses or copyright permissions allow redistribution. Free access or downloading does not automatically grant permission to republish a resource.

Preserve required attribution, copyright notices, license files, and other license conditions. When redistribution is prohibited or unclear, provide a link to the original source instead of uploading a copy.

Check the terms of use for datasets, software, libraries, and other third-party resources before sharing them.

## Contribution Guidelines

Contributors should prioritize accurate, useful, accessible, and appropriately licensed learning materials.

- Organize resources into relevant directories.
- Use descriptive filenames.
- Include source links and licensing information.
- Avoid unnecessary duplication.
- Document data-cleaning and preprocessing steps.
- Explain analytical methods and assumptions.
- Include code and dependency information where applicable.
- Make examples reproducible whenever possible.
- Clearly document dataset limitations and potential biases.
- Keep materials technically accurate and up to date.

Contributions should encourage hands-on learning, critical thinking, statistical reasoning, responsible data use, research, and open collaboration.
